# Build or Survive

Two browser games built on Maze of Gains (playmog.xyz). Unofficial fan project by Florence (https://x.com/flxrnc), made during Deed Season.

- **Would You Survive?** (`index.html`) - 10 real positions recorded from real runs. One press each, then the real outcome.
- **Maze Builder** (`builder.html`) - build one floor with the game's enemies, traps, loot, weather and talents, survive it with the real rules, and share it as one link.

Static site, no build step: open `index.html` in a browser or deploy the folder as is.

Live: https://buildorsurvive.xyz
